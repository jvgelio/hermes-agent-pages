Política de Privacidade

Última atualização: outubro de 2026.

Este aplicativo ("Hermes Agent") é uma ferramenta de uso estritamente pessoal, operada por João Victor Gelio, usada para automatizar tarefas de produtividade pessoal via integração com APIs do Google Workspace (Gmail, Agenda, Drive, Docs e Planilhas).

Dados acessados

O aplicativo acessa, por meio da autorização OAuth concedida pelo próprio usuário titular da conta, dados de e-mail, calendário, arquivos de Drive, documentos e planilhas, exclusivamente para uso pessoal do titular.

Uso dos dados

Os dados acessados não são compartilhados com terceiros, não são vendidos, e não são usados para fins publicitários. São processados localmente pelo próprio usuário para gerar resumos, automações e tarefas pessoais.

Armazenamento

Tokens de autenticação são armazenados localmente no dispositivo do usuário. Nenhum dado é enviado a servidores de terceiros além dos próprios serviços do Google.

Revogação de acesso

O usuário pode revogar o acesso deste aplicativo a qualquer momento em https://myaccount.google.com/permissions.

Contato

Dúvidas sobre esta política podem ser enviadas para jvgelio@gmail.com.
